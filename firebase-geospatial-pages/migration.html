One-time Mavo → Firebase migration

Use this private utility once after Firebase is configured and your UID has been added to admins. Import JSON exports from your old Mavo GitHub backend. Do not upload secrets or private user data.

1. Projects JSON

Choose the JSON file exported from the old gis-projects-data GitHub repository. Accepted forms include an array of projects or an object containing a projects array.

2. Lab experiments JSON

Choose the exported lab.json or another JSON object containing an experiments array. Existing documents are not overwritten; this utility adds new records.

After migration, remove this page from your deployed site or restrict access to it.
